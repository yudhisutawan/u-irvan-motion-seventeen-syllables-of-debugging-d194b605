# Tournament — Seventeen Syllables of Debugging

Method (per `~/workspace/makefun/win-gap-playbook.md`): 11 candidates drafted, 5 culled
on first pass (see CANDIDATES.md), 6 finalists in a full round-robin — 15 pairs, each
judged head-to-head against the competition's own published judge brief (criteria in
order: 1. form 5-7-5 about debugging · 2. concrete + fresh centre image · 3. turn
between line 2 and 3 lands · 4. every word earns its place · 5. reads aloud cleanly).
No ties; margin 1 (by a hair) to 5 (overwhelmingly better).

## Finalists

- **A** — Three in the morning / the cursor blinks while I wait / but the bug blinks first
- **C** — One breakpoint, waiting / the loop slips past, unbothered / so the bug was me
- **E** — My print statements bloom / each one says: not here, not here / the bug says nothing
- **F** — My rubber duck stares / I explain the bug aloud / then I hear the fix
- **G** — Off by one again / the loop ends one short of done / so do I, tonight
- **H** — Works on my machine / the server says otherwise / Friday afternoon

## Winner: G — 16/20 across four scorings

> Off by one again
> the loop ends one short of done
> so do I, tonight

Why it wins, in the judge brief's own order:
1. Form: verified 5-7-5 (Off/by/one/a-gain = 5; the/loop/ends/one/short/of/done = 7;
   so/do/I/to-night = 5), 65 characters, about debugging.
2. Concrete + fresh: an off-by-one loop error — a specific, lived bug, not a vague
   statement about code.
3. Turn: the last line reframes the whole poem from the loop onto the debugger —
   the loop ends one short of done, and so does the person, tonight. Every judge
   that scored it complete cited criterion 3 for G's wins.
4. Every word earns its place: no filler; "again" and "tonight" do the emotional work.
5. Rhythm: reads like speech — "Off by one again" is something a debugger actually says.

No rebuild: the winner leads the full 60-game aggregate and is the only haiku
picked outright by two judges. The panel split (G/G/E/C) is a sign the top three
are close, not that the winner is weak.
Runner-up: C (breakpoint), 14/20; third: E (print statements), 13/20.
